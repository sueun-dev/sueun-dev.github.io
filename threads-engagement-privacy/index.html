Threads Engagement Desk Privacy Notice

Effective September 10, 2026

Threads Engagement Desk is a local operator tool for reviewing public Threads posts and preparing replies. It is not a public service.

Information used

The tool may process public post text, public profile names, post URLs, timestamps, and engagement metadata selected by the operator. When its owner connects a Threads account, the OAuth access token and app credentials are stored only in the tool's local configuration on that owner's device.

Use and disclosure

Information is used only to review candidates, produce reply drafts, and publish a reply when the operator expressly confirms it. The tool does not sell personal information or provide it to advertising networks.

Retention and security

The operator controls local retention. OAuth credentials are not returned to browser JavaScript or exposed through the tool's API responses. A connected account can revoke authorization in Threads or Meta at any time.

Questions and requests

For privacy or deletion requests, email sueun.dev@gmail.com.
